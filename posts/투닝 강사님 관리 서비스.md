# 기존 투닝 강사님 관리자 시스템

![[file-20260423181851837.png]]
>기존 강사님 Pro 구독 관리 방식은, Pro 구독 시작일과 Pro 구독기간이 같은 강사님들을 묶은 ***가상의 학교를 생성하여 학교관리 시스템을 통해 관리***하는 방식이었습니다. 이러한 방식은 혜택과 같이 일괄적으로 Pro 권한을 부여할 때는 큰 문제가 없지만, 이어지는 ***강사님 마다 서로 다른 Pro 구독 연장요청에 대응하기에 매우 어렵다***는 @Emily (이주연)의 의견에 대해 마케팅 팀원분들과 같이 고민하여 개선한 관리자 시스템입니다. 추가로 강사님들에게 월마다 정산을 해드려야하는 작업이 있어, 정산을 위한 강사님 개인정보 또한 다룰 수 있도록 작업하였습니다.

# 투닝 강사님 관리 서비스 접속방법

1. 기존 어드민과 동일하게, 관리자 계정으로 접속하여 투닝 메인페이지 URL 뒤에 `admin` 을 붙여 관리자 서비스에 들어갑니다.
2. 페이지 내 관리 메뉴에서 `회원관리` 서비스로 이동 후, 최상단 관리 탭에서 `투닝 강사님 관리탭` 을 선택합니다.

![[file-20260423181902100.png]]

# 강사님 신규 등록

우하단의  `+`  플로팅 버튼을 클릭하면 아래와 같은 팝업 화면이 나옵니다.
팝업 화면 최상단 탭에서 1명의 강사님을 추가 할지, 여러명의 강사님의 정보를 엑셀파일을 통해 업로드 할지 선택할 수 있습니다.
- 두 작업 모두 해당 **강사님이 투닝 서비스에 가입된 이메일이 존재**해야만 합니다!
- 만약 **같은 이메일로 2가지 이상의 로그인 방식**(SNS, 커스텀 로그인) 투닝에 가입된 상태라면, **가장 최근에 가입한 계정**에 강사님 정보와 Pro 구독 권한이 부여됩니다. 
- 이미 유효한 Pro 구독이 진행중인 강사님을 `Pro 구독기간` 을 선택하지 않고 등록 요청 시, 시작기간이 설정되지 않습니다. 이로인한 버그는 없으나, `강사님 관리탭` 에서 관리되지 않는 상태임을 알리기위해 강사님 조회화면(상세보기X)에서는 보이지 않습니다!
![[file-20260423181913050.png]]

## 개별등록 방식

개별등록 폼에서 강사님을 추가할 때, **필수정보(이메일)를 누락**하거나 **유효하지않은 정보(휴대폰번호 등)를 입력** 시 **등록버튼이 비활성화** 됩니다. 등록 불가 사유는 잘못 입력된 항목 우측에 오류 사항이 표시 되므로, 확인 후 수정하시면 등록버튼이 다시 활성화 됩니다.
![[file-20260423181926473.png]]
## 일괄등록 방식

![[file-20260423181935414.png]]
일괄등록 폼에서는 여러 강사님들의 정보를 기입할 수 있는 엑셀 파일을 `강사님 일괄등록 엑셀 파일 다운로드` 버튼을 통해 받을 수 있습니다. 2번째 행에 입력 예시를 작성해두었으니, 확인 후 데이터 기입 부탁드립니다.
내려받은 엑셀 파일의 일부 항목에 엑셀의 데이터 유효성 필터가 설정되어 있습니다.
임의로 해제하고 요청해도 **서버측에서 추가로 데이터 검사를 수행**하기에, 검증에 문제가 있다면 개발팀 @Carry (박종호)에게 문의 부탁드립니다.

# 강사님 정보 조회 방법

`투닝 강사님 관리탭` 강사님 목록에서 페이지를 넘기며 찾거나,
`투닝 강사님 관리탭` 바로 아래 위치한 검색 창을 통해 조회하실 수 있습니다.

## 페이지 탐색

페이지의 정렬 순서는 관리 서비스에 등록된 순서이며,
정렬기준 선택기능은 검색 창으로 대체가능하다 판단하여 구현하지 않았습니다.

## 강사님 검색 기능

검색 기능은 등록된 강사님 데이터 항목 모두에 대해 키워드와 정확히 일치하는 경우를 표시하도록 구현했습니다.
ex. `2025-02-06` 으로 검색 시, 전체 강사님 데이터(이메일,전화번호 등)에서 하나라도 정확히 일치한다면 표시
![[file-20260423182001257.png]]
# 강사님 상세정보 보기 및 정보 업데이트

특정 강사님 항목을 클릭 시, 상세정보 보기 및 정보 업데이트 팝업 화면이 열립니다.
![[file-20260423182012609.png]]
* 강사님을 특정하는 ID인 이메일 정보는 변경할 수 없습니다.
* 강사님 개별등록 화면과 마찬가지로 변경된 정보에 대해 검증이 실행되고, 문제가 있을 시 오류 메시지와 함께 업데이트 버튼이 비활성화 됩니다.
* 주민번호와 같은 처리에 유의해야하는 개인정보는 담당자로 지정된 특정 계정이나 강사님 본인만 조회 및 수정할 수 있습니다. (다음 배포에 업데이트 예정)

# 강사님 정보 삭제

![[file-20260423182023995.png]]
강사님 조회화면에 나타난 해당 강사님 탭의 우측 쓰레기통 아이콘을 클릭하면, 강사님 정보를 삭제할 수 있습니다.
실수로 삭제하거나 복구 요청에 대비해, **시스템에서 영구 삭제하는 것이 아니라 해당 데이터를 비활성 상태로 전환**하여 관리 페이지에 노출하지 않습니다. (추후에 일정기간이 지난 데이터에 대해 영구삭제 작업은 구현 예정)
삭제된 데이터는 **등록 요청을 통해 재활성화** 될 수 있습니다. (단, 조회나 업데이트는 불가)

# 강사님 Pro 구독기간 변경 추적

빠른 적용을 위해 별도의 UI는 구현하지 않았지만, 서버에서 발생하는 강사님 Pro 구독 변경요청에 대해 기록을 남기도록 설정하였습니다. 만약 구독기간에 문의가 들어와서 변경기록 조회를 원하시는 분들은 @Carry (박종호)에게 DM 남겨주세요. 요청이 많아질 경우, UI 를 추가 구현할 예정입니다.
또한, Pro 구독기간 변경 외에 사항의 추적이 필요하다고 생각하신다면 이 글 쓰레드에 남겨주세요!
