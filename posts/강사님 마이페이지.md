# 개요

현재 투닝에 소속된 강사님들의 정보는 [[투닝 강사님 관리 서비스]]를 통해 관리 중인데,
이를 매번 문의를 통해 업데이트하는 업무 프로세스는 비효율적인 것 같다는 에밀리의 의견에서 시작된 서비스입니다.
즉, 강사님들의 개인정보를 각자 로그인된 투닝 계정을 통해 업데이트할 수 있는 서비스입니다.
![[file-20260423173221654.png]]
# 변경가능한 정보 목록

`여러번 변경 가능` - 강사님 연락처, 주소, 활동 지역, 계좌번호
`최초 등록만 가능` - 주민등록번호

# 사용 방법

## 서비스 위치

1. 투닝 강사님 관리 서비스를 통해 등록된 강사님 계정으로 로그인
2. 투닝 랜딩 페이지 > 내 계정 탭 > 강사정보 탭 접근

## 개인정보 변경 요청

각 정보 별 우측에 위치한 추가/편집 버튼 클릭 > 나타나는 정보 업데이트 모달을 통해 요청
연락처/계좌번호/주민등록번호의 경우, 입력한 개인정보의 포맷이 맞지않을 경우 에러메세지 출력 및 업데이트 버튼 비활성화

### 1. 연락처

![[file-20260423173243848.png]]
유효한 통신 사업자 시작번호 (010, 017 ,018, 019)로 시작해야만하며,
중간 자리수는 3-4 자리, 마지막 자리수 4자리여야만 업데이트 가능
올바른 예시) 01x-xxx-xxxx 또는 01x-xxxx-xxxx

### 2. 주소

![[file-20260423173254235.png]]
검색버튼을 눌러 팝업되는 도로명 주소 검색 서비스를 통해 우편번호와 도로명 주소를 채워넣으면 업데이트 요청 가능
(자동으로 채워진 우편번호/도로명 주소 정보 수정 가능)
맨 아래 세부주소 정보는 선택사항

### 3. 활동 지역

![[file-20260423173303802.png]]
팝업되는 업데이트 모달에서 선택상자를 통해 원하는 지역 선택 가능


### 4. 계좌번호

![[file-20260423173312537.png]]
좌측 선택상자에서 은행 선택 후, 계좌번호 정보 입력 시 등록 가능
계좌번호의 자릿수는 10-14 자로 제한

### 5. 주민등록번호

![[file-20260423173320602.png]]주민번호 앞자리와 뒷자리를 알맞은 칸에 입력 시 등록 가능
주민번호 앞자리의 경우, 유효한 연도 형식(yymmdd)이 아니라면 에러 표시 및 업데이트 버튼 비활성화
주민번호 뒷자리의 경우, 첫번째 수가 1 ~ 4 사이의 수가 아니거나, 총 7자리 수가 아니라면 에러 표시 및 업데이트 버튼 비활성화
