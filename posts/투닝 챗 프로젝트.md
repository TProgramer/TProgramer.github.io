> 이미지 필터링 관련

생성된 이미지는 AWS Rekognition을 통해 필터링하여 문제가 없다면 사용자에게 보여집니다.
(필터링 걸릴 시, 생성 실패 메세지만 표시됩니다.)

적용된 필터는 아래와 같습니다.

- 성적으로 노골적이거나 누드가 포함된 콘텐츠
  - 노골적인 누드 콘텐츠
  - 실제 또는 시뮬레이션된 성적 행위
  - 성적 자극이나 쾌락을 위한 도구
  - 비노골적이지만 노출이 있는 콘텐츠
- 폭력적이거나 유혈이 낭자한 콘텐츠
  - 매우 잔인하거나 충격적인 폭력
  - 신체적 폭력이나 싸움
  - 무기를 사용한 폭력
  - 총기, 칼 등의 무기
- 시각적으로 불쾌하거나 충격적인 콘텐츠
  - 죽은 사람이나 동물의 시체
  - 목을 매는 장면
- 약물 또는 담배 관련 콘텐츠
  - 약물이나 마약 제품
  - 약물 사용 장면
  - 담배나 전자담배 제품
  - 담배를 피우는 장면
- 알코올 음료 관련 콘텐츠
  - 술병이나 술잔
  - 술을 마시는 행위
- 욕설이나 무례한 손동작
  - 가운데 손가락을 세우는 제스처
- 도박 관련 콘텐츠
- 혐오 단체나 극단주의 관련 상징
  - 나치 관련 상징이나 깃발
  - KKK나 남부연합기 등
  - 극단주의나 테러 단체 깃발
- 수영복이나 속옷을 착용한 콘텐츠
  - 여성 수영복이나 속옷 (비키니, 란제리 등)
  - 남성 수영복이나 속옷 (트렁크, 브리프 등)

## 번외

### Vector Search Indexer / Retriever

`vertexAiIndexerRef()`와 `vertexAiRetrieverRef()`를 통해 **Vertex AI Vector Search 인덱스**와 연결.

1. 임베딩 모델 결정

* multimodal-embedding-001

1. 임베딩 생성 & 인덱싱

```
await ai.index({
  indexer: vertexAiIndexerRef({ indexId }),
  documents  // Document.fromText(chunk, metadata)
});
```

2. 질문 수신 → 리트리브

```
const docs = await ai.retrieve({
  retriever: vertexAiRetrieverRef({ indexId }),
  query: userQuestion,
  options: { k: 5 }
});
```

3. 프롬프트 증강 & 생성

`ai.generate({ prompt, docs })` 를 호출하면 Genkit이 `docs` 내용을 system/context 섹션에 자동 삽입

4. 컨텍스트 캐싱 결합 (선택)

* 대형 매뉴얼 전체를 첫 호출에서 캐시하고 캐시 ID를 세션 state에 저장 →후속 질문은 캐시 ID만 포함해 토큰·비용을 절감하고도 동일 문맥을 유지

### 비용·성능 관리

1. **Chunk 크기 실험** – 짧으면 검색 정밀, 길면 캐싱 단가↓.
2. **k 값 튜닝** – 3-5 개가 흔한 기본; 10 개 이상이면 reranker 적용이 효과적[Firebase 문서](https://firebase.google.com/docs/genkit/rag?utm_source=chatgpt.com).
3. **지연 시간** – 인덱스와 LLM을 같은 리전에 두면 30-40 ms 단축 [Google Cloud 문서](https://cloud.google.com/vertex-ai/docs/vector-search/quickstart?utm_source=chatgpt.com).
4. **캐시 최소 토큰** – Flash: 1024, Pro: 2048 토큰 미만은 캐시가 안 붙으므로 문서를 묶어 보내야 함 [Google AI for Developers](https://ai.google.dev/gemini-api/docs/caching?utm_source=chatgpt.com).
5. **비용 시뮬레이션** – Vector Search는 **GB 당 ingest 비용+VM 시간당 과금**이므로, 문서가 적을 땐 dev-local 또는 Chroma 같은 임베디드 DB가 더 경제적 [Firebase 문서](https://firebase.google.com/docs/genkit/rag?utm_source=chatgpt.com).
